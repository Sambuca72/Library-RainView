# Данные примеров

Оба CSV искусственные, созданы с фиксированным seed NumPy `2026`. Это учебные
иллюстрации, а не результаты исследования реальных студентов или участников.

`education.csv`: 150 строк, три группы по 50 исходных строк. Два значения `score`
и одна метка `method` пропущены намеренно. После очистки остаются три группы
по 49 наблюдений. Группа «Смешанный» содержит две компоненты распределения.

`distributions.csv`: 360 строк, три группы по 120 значений. Компактное нормальное,
смесь двух нормальных распределений и гамма-распределение центрированы отдельно,
поэтому средние практически одинаковы. Шкала числового показателя условная.
