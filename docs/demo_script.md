# Демонстрация RainView

Это сценарий короткой защиты реализации. Начните с результата: библиотека
получает DataFrame и одним вызовом возвращает график распределений и проверяемую
сводку по данным.

## Первый график

Откройте `examples/01_quickstart.ipynb` или готовый `demo_output/education.png`.
Объясните три слоя: плотность показывает форму распределения, boxplot — медиану,
квартили и усы, точки — каждое реальное измерение. Слои разнесены по ширине группы,
поэтому точки не закрывают ящик. Все демонстрационные данные искусственные.

Покажите одну команду `fig, ax, summary = raincloudplot(...)` и текстовую сводку.
В исходном CSV 150 строк, на графике 147 наблюдений: две оценки и одна метка группы
пропущены. Библиотека сообщает об очистке, а счётчики позволяют проверить результат.

## Зачем нужны распределения

В ноутбуке 02 три выборки имеют практически одинаковое среднее, но разную форму.
Покажите, что среднее не раскрывает два пика и длинный хвост. Переключение в
горизонтальную ориентацию, смена палитры и порядка групп не требуют сборки слоёв
вручную. График не является статистическим тестом.

## Ошибки данных

В ноутбуке 03 покажите понятные сообщения об отсутствующем столбце, строковом
измерении, пустой группе и числе наблюдений меньше пяти. Затем покажите постоянную
группу: вместо искусственной плотности появляется линия с предупреждением.

## Как устроен код

Откройте `docs/implementation.md`. Опишите путь: проверка → очистка → группировка →
статистика → слои → Figure/Axes/summary. Отдельные модули отвечают за данные,
рисунок, отчёт и ошибки. Все вычисления выполняются локально.

## Проверка и экспорт

Покажите `verification/REPORT.md`, успешный pytest и измерения на 10 000 строках.
Результат производительности относится к проверенному компьютеру. В конце
откройте PNG и SVG: они создаются только по явному запросу пользователя.

Для живого запуска из папки проекта:

```bash
.venv/bin/python examples/make_figures.py
.venv/bin/python -m pytest -q
```
