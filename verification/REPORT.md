# Проверка реализации RainView

Дата проверки: 19 октября 2026 года. Реализованы три функции MVP, описанные в
документах команды. Здесь зафиксированы технические проверки; они не являются
подтверждением спроса со стороны реальных пользователей.

## Автоматические тесты

77 тестов проходят в обоих проверенных окружениях:

| Компонент | Основное окружение | Окружение совместимости |
| --- | --- | --- |
| Python | 3.14.6 | 3.12.3 |
| NumPy | 2.4.6 | 1.26.4 |
| pandas | 3.0.3 | 2.1.4 |
| Matplotlib | 3.11.0 | 3.6.3 |
| SciPy | 1.18.0 | 1.11.4 |
| pytest | 9.0.3 | 7.4.4 |

Точные версии и платформа также записаны в `environment.txt`. Python 3.10
заявлен как нижняя поддерживаемая версия языка; отдельный прогон на нём не выполнен.

Проверены отсутствие столбцов, неверные типы данных, повторные и многоуровневые
имена столбцов, пропуски, пустые группы, минимум пять наблюдений после очистки,
минимум две группы, бесконечности и неверные параметры. Проверены числовые и
категориальные метки, неиспользованные категории и повторяющийся индекс DataFrame.

Описательная статистика сравнивается с pandas; исключённые строки учитываются
без двойного подсчёта. Проверены сохранность исходной таблицы, локальность
генератора случайных чисел и одинаковые координаты jitter при повторном seed.

Для графики проверены обе ориентации, порядок, подписи, палитры, положение слоёв,
выключение boxplot и точек, постоянные группы, реальная отрисовка и отсутствие
самопроизвольной записи файлов. Экспорт проверяется по сигнатуре PNG и структуре
SVG. Предупреждения в тестах трактуются как ошибки, если тест явно их не ожидает.

## Ноутбуки и визуальная проверка

Все три ноутбука выполнены через nbclient с ядром текущего интерпретатора:

- `01_quickstart.ipynb` — чтение CSV, очистка, график, сводка, PNG/SVG.
- `02_distributions_and_style.ipynb` — форма распределений, ориентация, стиль.
- `03_validation_and_reproducibility.ipynb` — ожидаемые ошибки и воспроизводимость.

Ожидаемые ошибки перехватываются и объясняются в ячейках. В ноутбуках нет
незавершённых ячеек или выходов типа `error`. Результаты выполнения сохранены.
Готовые вертикальный и горизонтальный рисунки проверены визуально: подписи
читаются, слои разнесены, значения точек и границы соответствуют данным.

## Производительность

Измеряется вызов `raincloudplot` вместе с `fig.canvas.draw()` при backend Agg,
по три повтора. Загрузка Python и импорт зависимостей исключены; все наблюдения
участвуют в KDE и отображаются точками. Подробные результаты — `benchmark.json`.

| Строк | Групп | Медиана, с | Максимум, с | Требование |
| --- | --- | --- | --- | --- |
| 10 000 | 3 | 0.050 | 0.061 | не больше 5 с, выполнено |
| 10 000 | 10 | 0.088 | 0.090 | не больше 5 с, выполнено |
| 100 000 | 3 | 0.225 | 0.265 | проверка целевого объёма, порог не задан |

Это измерения на данном компьютере и указанном окружении. Другой процессор,
графический backend и состояние системы могут изменить время.

## Упаковка и запуск

Пакет собирается как `rainview-0.1.0-py3-none-any.whl` и исходный архив
`rainview-0.1.0.tar.gz`. Wheel проверяется установкой без повторной загрузки
зависимостей в отдельное временное окружение и вызовом публичного API из папки,
где нет исходников. Проверка включает фактическое сохранение PNG/SVG.

В папке проекта подготовлено `.venv` с доступом к установленным библиотекам
Anaconda и локальной установкой RainView. Для переноса на другой компьютер
нужно создать новое окружение по инструкции в README.

Ruff проверяет Python-файлы и код ноутбуков. Примеры данных искусственные,
пользовательские таблицы в ходе проверки не использовались.

## Воспроизведение

Из корня проекта в активированном окружении:

```bash
python -m pytest -q
python -m ruff check src tests scripts examples
python -m ruff format --check src tests scripts examples
python scripts/benchmark.py
python scripts/execute_notebooks.py
python examples/make_figures.py
python -m build
```

## Практические границы

Фокус MVP — 2–10 групп и малые или средние выборки. При 5–19 наблюдениях
выдаётся предупреждение об оценке плотности; меньшая группа вызывает ошибку.
Постоянная или численно вырожденная плотность заменяется линией с предупреждением.
Более 10 групп или 100 000 строк разрешены с предупреждением.

Ширина KDE нормирована отдельно по группам, число наблюдений нужно читать в
сводке. Используемое сглаживание может скрывать детали распределения. Библиотека
не вычисляет p-value, не делает выводов о значимости и не выполняет причинный анализ.
