# Исходные требования

Здесь сохранены неизменённые копии двух документов команды: бизнес-гипотезы и
архитектуры проекта. Требования к реализации извлечены из обоих документов.
При расхождении краткого примера API и подробного технического задания выбран
контракт архитектуры: `fig, ax, summary` и минимум пять наблюдений на группу.

Описание принятой реализации и остальных уточнений находится в
`docs/implementation.md`.
